# Research writing with the Anthropic corpus as reference

Use wiki/style/ for examples of clear explanation, useful figures and linked sources. The corpus is not a template to imitate and is not a restriction on data or literature. PROJECT.md and Emily's latest editorial directions take precedence over historical style annotations.

Lead with the question's stakes and what the evidence adds. Explain the comparison behind each finding. Prefer concrete language, fluent transitions, informative headings, selective bold emphasis and hyperlinks at the point of use. Preserve the current author's manuscript and voice. Use no first person unless Emily requests otherwise.

Define generative AI accurately and identify broader AI measures separately. Name the actual survey/platform, sample, date and unit; do not label non-Claude findings as Claude. Separate descriptive findings, possible explanations and causal evidence.

Technical detail should be available in methods/appendices while key limitations remain near the claims they qualify. Do not impose exact quotas for bold, a numberless opening, compulsory hypothesis tables, a limitations section that must withdraw a claim, or recommendations to a provider. A claim map supports accuracy; it is not the prose outline.

For an assigned draft: read relevant evidence, edit, render, inspect figures and perform a cold-reader pass. Emily reads a new draft before a review agent is commissioned. Use the existing article's own build system; do not assume the old page builder on post1-draft exists on main.
