## The claims list is the boundary; the verifier binds per sentence (keywords: claims.md, boundary, verifier, per-sentence binding, captions, wage bill, brief §2, Stage 3, post1)
Added 2026-09-17 (session 2.1, post1 Stage 3). (1) Writing claims.md (referee, before any prose) and holding the editor to it removed five sentences the editor wanted, including the brief's own §2 wage-bill framing and §12's "twelve points" — both forbidden once the results existed. Briefs should write why-it-matters in the language the measure supports (an hourly rate, a model input) and write bounds as "the realised bound in results.json", not a number. (2) A page verifier that checks each number occurs somewhere in results.json passes coincidences (23, 100, $10); it must check that each number is a rounding of a value its own sentence's claims-map bindings resolve to. Implemented in site/tools/verify_page.py check 3. (3) Captions were the leakiest surface: four defects across two reviews, one prescribed by the referee itself. The analyst's figures.json is the caption of record; the editor binds to it; both review points check captions against the plotted data.
