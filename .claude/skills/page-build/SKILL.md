# Page building and verification

Use the assigned study's documented build system; preserve author edits. The current Eurostat article lives in the separate gender-gap-generative-ai repository. Its live author-edited HTML is authoritative pending line-edit integration; regenerating its Markdown does not synchronise those edits automatically.

The older site/tools builder and verifier exist on the parked post1-draft branch, not on main. Do not merge that branch or create a replacement article merely to reuse the tools.

For new outputs, bind empirical values to checked results and provenance, verify source links and figures, and inspect the rendered page for clipping, unreadable text, ambiguous legends and broken navigation. Distinguish external cited statistics from own empirical estimates. Exported PDFs should correspond to a recorded manuscript version. Report exactly which artifact was checked and remaining limitations.
