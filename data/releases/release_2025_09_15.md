## Grains

**One row = one (geography, facet, level, variable, cluster) cell for the single week.**
The nine-column key `geo_id, geography, date_start, date_end, platform_and_product, facet,
level, variable, cluster_name` is **unique with zero duplicates** in all three files
(136,845 / 136,845 enriched; 100,062 / 100,062 raw Claude.ai; 33,794 / 33,794 API).

- `geo_id`/`geography` are redundant with each other except that `geo_id` carries the
  `not_classified` bucket at both country and state level.
- `level` is meaningful only for `request` and `request::collaboration` (0 = finest, 2 = coarsest,
  matching the report's "lowest / middle / highest" wording). It is 0 everywhere else.
- `cluster_name` carries `base::category` for the intersection facets; split on the **last** `::`
  (`str.rsplit("::", n=1)`, as the released `get_collaboration_shares` does) — task names can
  themselves contain `::`-free commas but the base is always to the left of the final separator.
- The panel is **ragged**: a cell absent means suppressed or zero, and the file does not
  distinguish the two. See *Coverage counts*.

### The AUI construction, exactly

From `aei_report_v3_preprocessing_claude_ai.ipynb` → `calculate_usage_per_capita_index`, with
`filtered_countries` produced by the **notebook's** `get_filtered_geographies`, which — unlike the
identically-named function in `aei_analysis_functions_claude_ai.py` — **does not drop
`not_classified`**:

```
filtered      = { geo_id : usage_count >= 200 }            # includes 'not_classified'
total_usage   = sum(usage_count over filtered)             # so it includes not_classified
total_pop     = sum(working_age_pop over filtered)         # not_classified has no pop row -> 0
AUI[g]        = (usage_count[g] / total_usage) / (working_age_pop[g] / total_pop)
```

The index is then written for **every** country with usage data and positive population, not
only the thresholded ones. Reproduced exactly (max abs. difference **0.00000000** over 194
countries; USA 3.624352). The three plausible alternatives are wrong: usage over thresholded
countries *only* is off by up to 1.31 (USA 4.300303); usage over all countries including
`not_classified` is off by up to 0.20; usage over all countries *excluding* `not_classified` by
up to 1.54. **This confirms the `economic-index-data` skill to full float precision, not just
five decimals.**

## Thresholds

**The public files do not apply any of them.** The constants live in the code:
`MIN_OBSERVATIONS_COUNTRY = 200`, `MIN_OBSERVATIONS_US_STATE = 100`
(`aei_analysis_functions_claude_ai.py` lines 48–49; repeated in the preprocessing notebook).

Evidence that they are not applied:

- The raw Claude.ai file has 173 country `usage_count` rows of which **57 are below 200**
  (minimum 16).
- The enriched file has 201 country `usage_count` rows of which **85 are below 200**
  (28 of them exactly 0 — countries added from the population table with no observed usage).
- **79 countries carry an `usage_per_capita_index` (AUI) row despite being below 200.**
- States: 52 `usage_count` rows, one below 100 — that row is the `not_classified` bucket
  (value 2). All 51 real states clear 100.
- `get_filtered_geographies(df)` returns **115 countries and 51 states**.

Other thresholds and rules that are *baked into* the published files:

- **Privacy floor.** `onet_task_count`, `request_count` and the API counts have a hard minimum of
  **15** (0 rows below). `collaboration_count` is the exception: minimum 1, with 50 rows below 15.
  The report's footnote about ≥ 500 conversations / ≥ 250 accounts for bottom-up request clusters
  governs cluster *formation*, not the per-cell floor — Claude.ai `request_count` cells go down
  to 15, while the API's `request_count` minimum is 556.
- **`EXCLUDED_COUNTRIES`** (23 ISO-3 codes, above) — countries where Claude is not offered. They
  have no usage rows and are not padded in by the enrichment.
- **Tier quartiles** are computed over thresholded geographies only, then applied to everyone.
  Countries: cutpoints 0.361773 / 0.848593 / 1.773097 (quartiles of the 115 thresholded AUIs);
  observed bands `Minimal` [0, 0] n=28 · `Emerging` [0.0144, 0.3579] n=53 ·
  `Lower middle` [0.3656, 0.8486] n=40 · `Upper middle` [0.8865, 1.7111] n=36 ·
  `Leading` [1.8351, 7.0038] n=37. States: cutpoints 0.428226 / 0.698012 / 0.932861;
  bands n=13/13/12/13, no `Minimal` tier.
- **Figure request filter**: ≥ 1% of requests both locally and in the parent geography
  (`filter_requests_by_threshold`, default `level=1`).

Suppression is **silent**: an absent cell and a true zero look the same. The only explicit
zeros are the 28 padded countries' `usage_count`/`usage_pct`.

## Traps

1. **`NA` is Namibia.** Reading either Claude.ai file with pandas defaults turns 22 rows'
   `geo_id` into `NaN` and silently loses a country. Always
   `pd.read_csv(..., keep_default_na=False)`. The notebooks use
   `keep_default_na=False, na_values=[""]`. **Anthropic's own
   `aei_analysis_functions_1p_api.load_preprocessed_data` does not** — it is plain
   `pd.read_csv`, so `cai_df` loaded through it is missing Namibia. Harmless for the API chapter
   (global rows only); not harmless if reused for geography.
2. **Two different automation denominators in one report.** The enriched file's `automation_pct`
   excludes `none` and `not_classified` (Claude.ai global 51.0698). The report's headline
   numbers — 49% Claude.ai, 77%/12% API — include them (49.0980, 77.3723, 12.4146). Figure 2.11
   and the enriched variable use the 51.07 base; Chapter 1's Figure 1.2 and Chapter 3's prose use
   the 49.10 base. State and country `automation_pct` rows use the five-pattern base. **Say which
   base you are on, every time.** (The `economic-index-data` skill gives only the five-pattern
   rule; that is right for the file's variable and wrong for the report's headline.)
3. **Figure 3.4's Gini and its bottom-80% number come from different task universes** — see
   *Reproduced published numbers*.
4. **Chapter 1's prose percentages are un-renormalised; the released script renormalises by

5. **Thresholds are not applied.** 85 of 201 country rows and 79 of 194 AUI rows are below 200
   conversations. Always call `get_filtered_geographies` first.
6. **Two different `get_filtered_geographies`.** The library version drops `not_classified`
   (115 countries); the preprocessing-notebook version does not (116). The AUI depends on the

   notable fraction of its usage appeared to be possibly associated with coordinated abuse. This

def gini(v):
    s = np.sort(np.asarray(v, float)); n = len(s); c = np.cumsum(s)
    return (2*np.sum(np.arange(1, n+1)*s))/(n*c[-1]) - (n+1)/n
