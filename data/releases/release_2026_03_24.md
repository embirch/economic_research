## Grains

One row = one metric value for one (geography, facet, level, variable, cluster). The key
`(geo_id, geography, facet, level, variable, cluster_name)` is **unique in both files** — 0
duplicates — so the files can be pivoted without aggregation.

```bash
python3 -c "
import pandas as pd
k=['geo_id','geography','facet','level','variable','cluster_name']
for t in ['claude_ai','1p_api']:
    d=pd.read_parquet(f'data/cache/release_2026_03_24/data/aei_raw_{t}_2026-02-05_to_2026-02-12.parquet')
    print(t,len(d),d.drop_duplicates(k).shape[0],len(d)-d.drop_duplicates(k).shape[0])"
# -> claude_ai 477717 477717 0 ; 1p_api 195156 195156 0
```

Three geographic grains in the Claude.ai file and one in the API file:

- **global** — `geo_id='GLOBAL'`. The only grain that carries intersections, histograms and
  confidence intervals on the numeric facets.
- **country** — ISO **3166-1 alpha-2** (two letters, not the three-letter codes of the
  2025-09-15 *enriched* file). 178 `geo_id`s with a `usage_count`: 176 real countries plus the
  pseudo-codes `not_classified` (181,586) and `NONE` (2,340).
- **country-state** — ISO **3166-2** subdivisions **worldwide**, not US states. 1,256 regions
  across 155 parent countries. The US contributes 54 (`US-AL` … `US-WY`, plus `US-DC`, `US-GU`,
  `US-PR`, `US-VI`). There is no `state_us` facet in this wave.

```bash
python3 -c "
import pandas as pd
d=pd.read_parquet('$C.parquet')
u=d[(d.facet=='country')&(d.variable=='usage_count')]
print('country geo_ids',u.geo_id.nunique(),'pseudo',[g for g in u.geo_id if not (len(g)==2 and g.isupper())])
s=d[(d.facet=='country-state')&(d.variable=='usage_count')]
print('regions',len(s),'parents',s.geo_id.str.split('-').str[0].nunique(),'US-*',s.geo_id.str.startswith('US-').sum())
print('US-* codes',sorted(s[s.geo_id.str.startswith('US-')].geo_id.str[3:]))"
```

`not_classified` carries **only** the two `country` facet rows (`usage_count`, `usage_pct`).
`NONE` is a full pseudo-geography with 288 rows across 13 facets — treat it as "country not
determined", and drop both before any country analysis.

## Facets or categories

34 facets in the Claude.ai file, 38 in the API file. **The facet and variable sets are identical
to the 2026-01-15 wave** — nothing was added or removed between the fourth and fifth reports.

**What the fifth report's three Chapter-2 headlines have in the file** (added 2026-09-16, batch-2
Q12). Of tenure, task success and model class: **`task_success` is published**, as a binary
categorical facet (`yes` **69.938%** / `no` 30.062% at global) at all three geographies — `global`,
`country`, `country-state` — and additionally as `onet_task::task_success` and
`request::task_success` at global, so success by task and by request cluster exists. **Tenure and
model class do not exist at any grain**: no `facet` or `variable` name in either file matches
`tenure|seniority|experience|model|opus|sonnet|haiku|version|cohort|expert`, and
`platform_and_product` carries the single value `Claude AI (Free, Pro, and Max)` (API: `1P API`).
So the report's learning-curve and model-selection results are log-level with no public file, while
its success *levels* are reproducible and its success *regressions* are not. Verified:

## Metrics

166 variables in the Claude.ai file, 155 in the API file. They follow `{prefix}_{suffix}`:

- `usage_count` / `usage_pct` — facets `country`, `country-state`. **`usage_pct` is relative to
  the parent**: global for countries, the parent country for regions.
- `{facet}_count` / `{facet}_pct` for each categorical facet; `_pct` is the share of the
  geography's total.
- `{base}_{secondary}_count` / `_pct` for categorical intersections; the `_pct` sums to 100
  **within each base cluster**, not across the file.
- `{facet}_mean`, `_median`, `_stdev`, `_count`, `_mean_ci_lower`, `_mean_ci_upper`,
  `_median_ci_lower`, `_median_ci_upper` for numeric facets; `_histogram_count`,
  `_histogram_pct` at global only.
- `cost_index`, `prompt_tokens_index`, `completion_tokens_index` — API only, one value per
  O\*NET task and per request cluster, 1.0 = average.

**Counts are on a 1,000,000 sample base, not raw conversations.** Every global `{facet}_count`
sums to exactly 1,000,000 in both files; percentages are `count / 1e6 * 100`.

```bash
python3 -c "
import pandas as pd
d=pd.read_parquet('$C.parquet'); g=d[d.geography=='global']
for f in ['collaboration','use_case','task_success','multitasking','human_only_ability','onet_task','ai_autonomy']:
    print(f, format(g[(g.facet==f)&(g.variable==f+'_count')].value.sum(),',.0f'))"
# -> 1,000,000 for all seven
```

**Units.** `human_only_time` and `human_with_ai_time` are in **hours** in the file; the report
prints minutes (see Reproduced published numbers). `ai_autonomy` is the 1–5 scale of the primitive
prompt; `*_education_years` are 0–20 discrete years.

**No index metric is shipped.** There is no `usage_per_capita`, no `usage_per_capita_index` (the
AUI), no `usage_tier`, no `onet_task_pct_index`, no `working_age_pop` and no
`gdp_per_working_age_capita` — all of which the 2025-09-15 *enriched* file carries. The AUI must
be rebuilt (below), and the population it needs is not in this release.

```bash

## Thresholds

**No threshold is applied in the files, and this wave's documentation no longer states them.**
The 2026-01-15 `data_documentation.md` contained the line "Minimum Observations: 200
conversations per country, 100 per country-state region (applied in enrichment step, not raw
preprocessing)"; the 2026-03-24 documentation **deletes that sentence**, while still shipping raw
files with no enrichment step. The constants live only in the 2025-09-15 code
(`MIN_OBSERVATIONS_COUNTRY = 200`, `MIN_OBSERVATIONS_US_STATE = 100`, and
`get_filtered_geographies()` which drops `not_classified`).

     data/cache/release_2026_03_24/data_documentation.md | grep -i 'minimum observations'

```

Two further thresholds you must supply yourself, both from the 2025-09-15 library:

- **Request-cluster share threshold** — `filter_requests_by_threshold(..., threshold=1.0)`
  keeps a level-1 cluster only if it is ≥1% in *both* the geography and its parent (`GLOBAL` for
  countries, `USA` for states). Nothing in the file marks this.
- **Excluded countries** — the library's `EXCLUDED_COUNTRIES` (23 ISO-3 codes: AFG, BLR, COD,
  CAF, CHN, CUB, ERI, ETH, HKG, IRN, PRK, LBY, MLI, MMR, MAC, NIC, RUS, SDN, SOM, SSD, SYR, VEN,
  YEM). **None of their ISO-2 equivalents appears in this file** — Anthropic has already removed
  them upstream, so applying the list again is a no-op here. Verified: the intersection of the
  file's `geo_id`s with the mapped list is empty.

Suppression is by omission, not by a flag: there is no suppression column and no sentinel value.
Absent cells are simply absent rows. 1.07% of usage sits in geographies that were dropped
entirely — `country` `usage_count` sums to 989,313 of 1,000,000 (`usage_pct` sums to 98.9313).

### AUI rebuild and its denominators

The file carries no AUI. Anthropic's definition, from
`calculate_usage_per_capita_index()` in `release_2025_09_15/code/aei_report_v3_preprocessing_claude_ai.ipynb`:

> AUI(i) = (usage(i) / Σ usage over threshold-passing geographies) ÷ (pop(i) / Σ pop over the
> same geographies)

with `working_age_pop` = population aged **15–64**: World Bank `SP.POP.1564.TO` for countries
(Taiwan patched in from the national projection file) and Census `sc-est2024-agesex-civ.csv`
(`AGE` 15–64, `SEX==0`, drop `NAME=="United States"`) for US states. In the released code the
usage denominator is over threshold-passing countries only, **excluding** `not_classified`;
adding `not_classified` (as the `economic-index-data` skill says) rescales every AUI by the same
constant and therefore changes no Gini, no Lorenz curve and no top-*N* share. **This release
publishes no AUI level, so the denominator question cannot be settled from this wave** — only
from 2025-09-15, where the AUI is published.

## Traps

1. **`NA` is Namibia, `NONE` is a geography.** Read with `keep_default_na=False, na_values=[]`.
   Default pandas NA handling nulls 3,672 `geo_id` values in the Claude.ai file.
2. **Counts are per million, not conversations.** The 200-per-country threshold therefore means
   200 per million. Do not add counts across the two files or across waves as if they were
   volumes; the samples are both exactly 1M and carry no scaling factor to real traffic.
3. **`human_only_time` and `human_with_ai_time` are in hours.** The report prints minutes. Failing
   to multiply by 60 turns 183.77 minutes into "3.06".
4. **The automation denominator in this wave includes the `none` collaboration cluster.** The
   `economic-index-data` skill says "÷ the sum of the five classified patterns"; that gives
   45.55%/54.45% and does **not** match Figure 1.3's 44%/53%. Summing `collaboration_pct` over
   the five patterns against a base of 100 does. Re-check this per wave.
5. **The US `country` row excludes territories that the `US-*` rows include.** `country` `US`
   usage_count = 222,372; the 54 `US-*` rows sum to 223,004 = 222,372 + `US-PR` 587 + `US-GU` 26
   + `US-VI` 19. Consequently `usage_pct` over `US-*` sums to **100.284**, not 100. Region
   `usage_pct` is count ÷ *parent country* count × 100.
6. **`country` `usage_count` does not sum to 1,000,000** (989,313; `usage_pct` 98.9313). About
   1.07% of usage is in geographies suppressed entirely, on top of `not_classified` (18.16%) and
   `NONE` (0.23%).
7. **`not_classified` and `none` are different things and both appear as cluster names.** `none`
   means the attribute is absent, `not_classified` means privacy-filtered or unclassifiable. The
   published top-10 task figure requires dropping **both**; dropping only `not_classified` gives
   22.49% against the published 19%.
8. **Global `use_case` has `none` in this wave and `not_classified` in 2026-01-15.** Do not
   hard-code either name when comparing waves.
9. **Intersection `_pct` sums to 100 within each base cluster**, so `onet_task_collaboration_pct`
   summed over a file is ~325,900, not 100. Always group by the base.
10. **`request` level 0 exists for only 71 of 176 countries** and for 178 of 1,256 regions; the
    median country has 39 of 621 clusters. Level-0 mixes below global are not comparable.
11. **The request and task taxonomies change between waves** (621 level-0 clusters here, 588 in
    August 2025; 3,258 tasks here). Never diff cluster sets across waves without an explicit
    name match, and report the unmatched names.
12. **`*_median_ci_lower` can be negative** (one Claude.ai row, 46 API rows, minimum −0.755).
13. **`level` is 0 for every facet except `request*`.** Do not filter on `level` when selecting
    `onet_task` or the numeric facets — you will silently keep everything, which is fine, but
    joining on `level` across facets will produce spurious matches.
14. **`resolve/main` needs `curl -L`.** Without it you get a 325-byte stub with HTTP 200.
15. **The documentation dropped the threshold sentence** this wave (see Thresholds). Do not infer
    from its absence that the file is pre-filtered; 59 countries sit below 200.
16. **`request` `level` semantics are inverted from intuition**: 0 = finest, 2 = coarsest.
