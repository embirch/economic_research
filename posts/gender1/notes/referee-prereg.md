### (b) The class rule

**3. The class rule ranks the ratio the wrong way, defines no tercile for N = 26, no per-measure class for H-composition to compare, and no class for a geography lacking one measure. — BLOCKING. Prereg "The class rule" and H-composition "Test".**
(i) §3 defines `ratio = p_F / p_M` (as BRIEF §7). The class rule then says large-gap = "top tercile on all three" measures. The top tercile of p_F/p_M is the **smallest** relative male lead, so as written no country with a large gap can be classed large-gap; BRIEF §4 says "top tercile of the male-to-female ratio", which is the intended direction, and the brief is internally inconsistent between §4 and §7. (ii) The usable sets are 27 (gap), 27 (ratio) and **26** (standardised; IE lacks a usable 16–24 pair, `.out.txt` §C); "terciles" of 26 need a rule. (iii) H-composition's test says "classify each by the class rule below on the crude gap and on the standardised gap", but the class rule is a joint rule over all three measures, so "class on the crude gap" is undefined; the same gap affects "the number of geographies that change class between any two of the three measures". (iv) IE has a crude gap and a ratio but no standardised gap, so it can be neither large- nor small-gap under the rule; the rule must say what it is called, and it must not be "not distinguishable", which implies it was tested and fell in the middle. (v) The sampling bound does not enter the class rule at all; under a null in which every EU27 country has the **same** true gap and only its own SRS noise, the rule as written classes on average **4.2 countries large-gap and 5.9 small-gap of 26** (`.out.txt` §E; if the three measures were independent the figure would be 1.0). The three measures are the same cells re-expressed, so agreement across them guards against the choice of measure, not against noise; the post must not present the classes as noise-robust unless the bound qualifies them.

*Change.* Replace the paragraph "The class rule (fixed here, …)" with:

> **The class rule (fixed here, used by H-composition and by every "largest" statement).** *Per-measure tercile.* For each of the three measures — the signed gap on `PC_IND`, the ratio `p_F / p_M`, and the standardised gap — order the EU27 geographies with a usable value so that a larger male lead ranks higher (gap descending; ratio **ascending**, since a smaller `p_F / p_M` is a larger male lead; standardised gap descending). With N usable geographies, k = round(N / 3) (N = 27 → 9; N = 26 → 9); the top tercile is the k highest-ranked and the bottom tercile the k lowest-ranked, except that a geography whose value is within 0.1 point (ratio: within 0.01) of the (k+1)-th value from that end is **not** in the tercile (the tie rule). *Persistent class.* **large-gap** = top tercile on all three measures; **small-gap** = bottom tercile on all three; **reversed** = `p_F > p_M` on `PC_IND` and on `PC_IND_IU3`; **not classifiable** = no usable value on one of the three measures (at commit: IE, which has no standardised gap); otherwise **not distinguishable**. *Distinguishable class.* A large-gap or small-gap class is marked distinguishable if the geography's crude gap lies further than its 95 % half-width from the (k+1)-th value on the gap measure; a reversed class is marked distinguishable if `|gap| > half-width` on `PC_IND`. The class table carries both marks. Agreement across the three measures guards against the choice of measure, not against sampling noise (the same cells are re-expressed); the distinguishable mark is the only noise guard, and the post says so. *Class changes.* "A geography changes class between two measures" means its per-measure tercile differs between them, on the intersection of the two usable sets; H-composition counts this between the crude and the standardised gap on the 26 geographies with both; the same count between gap and ratio, and between ratio and standardised, is reported. Extension geographies are placed against the EU27 cut values, never inside them.

And in H-composition, replace "classify each by the class rule below on the crude gap and on the standardised gap" with "assign each its per-measure tercile (class rule below) on the crude gap and on the standardised gap", and replace "at most one third of those geographies change class. **Against:** more than one third change" with "at most 8 of the 26 change tercile (one third of 26 is 8.67). **Against:** 9 or more change".
